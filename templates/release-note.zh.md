# <版本号，如 R20261106.01 或 1.4.2>

> 用法：复制为 `docs/releases/<版本>.md`；发布前填 1–4、6、8、9，发布后补 5、7。
> 顺序：写本单 → 提交 → 构建 → 打 tag → `preflight --release` → 部署。发布后补结果的新提交不要移动 tag。
> 规范：`docs/standards/03-git-version-release.md` §4.5。缺项视为不合格。
