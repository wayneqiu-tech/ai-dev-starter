# CLAUDE.md

Read `AGENTS.md` first. It is the single source of project rules, boundaries, and
definition of done.

Project-specific additions for Claude Code:

- Prefer the smallest change that satisfies the task card.
- Show the plan before editing when the change touches more than 3 files.
- When you finish, provide the four-part self-proof from `AGENTS.md` §5.
- You may create a task branch and commit on it if `AGENTS.md` allows. Do not merge, push, tag, or deploy without approval.
