## 3. Change summary

- Next Action cards accept `title` and `body` in `details`.
- For GitHub `releases/new` URLs, the Client encodes `title` and `body` into
  the query string, so the release form opens prefilled.
- The body is also written to the clipboard on click as a fallback.
- Plugin version `0.1.6`.
