## 3. Change summary

- Fixed "card shows `settled` but AI does not respond".
- The card kind now builds a complete `UserMessage`:
  `id` + `role: "user"` + `content` + `source`.
- After recording `accepted`, it calls `agent.followup(message)` to wake the
  agent so the next turn receives the status notice and continues.
- `stop` still records `stopped` without waking.
- Plugin version `0.1.5`.

  pending.
- Still a public beta, not a formal standard or certification.
