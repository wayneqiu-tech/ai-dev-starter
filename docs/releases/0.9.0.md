## 3. Change summary

First public beta of AI Dev Standard: 7 bilingual guides, 30 pitfall patterns,
beginner entry (`START_HERE.zh.md`), templates, presets, `preflight.sh`,
`cleanup.sh`, `init-project.sh`, monitoring/auto-recovery guidance, and a
runnable example.

Positioning: **an opinionated engineering baseline / starter kit**, not a formal
standard. The 1.0 line will follow after real-world feedback.

## 7. Risks and open issues

- **Not a formal standard yet**: no conformance test suite, no RFC governance,
  no independent adoption evidence, no SLSA/Scorecard posture.
- The preflight script is heuristic: it catches common secrets/large files, not everything.
- Scripts print English messages; Chinese docs explain, but this is a known
  beginner friction point.
- Platform focus is macOS/Linux with GitHub Actions; Windows relies on Git Bash.
- English is a translation; if the two languages disagree, open an issue.
