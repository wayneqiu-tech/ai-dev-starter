## 3. Change summary

- Next Action Cards plugin now injects a **profile-level system prompt**:
  every agent in the profile must end a completed task with one Next Action Gate.
- The prompt prefers the real `next-action` card and falls back to
  `ask_user_question` when the plugin is unavailable.
- This removes the need to add the same closing rule to every workspace's
  `AGENTS.md`.
- Plugin version `0.1.2`; prompt section `ai-dev:next-action`, order `500`.

## 7. Risks and open issues

- The prompt applies to the whole profile, not one workspace; a project that
  does not want cards will still receive the closing rule.
- A fresh-profile install is still pending.
- Still a public beta, not a formal standard or certification.
