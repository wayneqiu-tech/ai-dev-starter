## 3. Change summary

- **Next Action Cards plugin** (`plugins/next-action-cards`): a real DSH
  Action Card bundle, not a template.
- Host half registers a card kind and the `next-action` skill.
- Client half registers the card body; URL actions are real links.
- Clicking records `accepted` / `stopped`; the next model request receives the
  status notice.
- Fixed the Body prop: `props.proposal.details` (not `props.card.details`).
- Added plugin README: install, field schema, verification, limits.
- AI Dev Standard skill now prefers the real card when `/next-action` is
  installed; otherwise falls back to `ask_user_question`.

## 7. Risks and open issues

- The plugin inserts `actionCards` host/client rows; do not enable it together
  with the personalized-recommendations action-card rows.
- Only the current DSH profile has been tested; a fresh-profile installation is
  still required.
- `command` details are passed through as text and are not executed by the card.
- Still a public beta, not a formal standard or certification.
